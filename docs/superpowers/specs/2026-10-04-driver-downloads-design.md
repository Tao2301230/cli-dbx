# 独立驱动固定下载入口

用户已确认固定入口与打包范围。所有交付位于 `cli-dbx/driver-downloads/`，压缩包文件平铺，名称包含引擎/路线、版本、平台和架构；包内部保留既有安装契约或厂商要求的布局。

收录 PG、Oracle、DM、SQL Server 独立 Go 驱动，目标 darwin/linux/windows 的 amd64/arm64；收录 Oracle/DM/SQLServer 独立 ODBC 适配程序；收录 Oracle、SQLServer、DM、OceanBase 厂商库/安装包。收集本机已有版本和公开可取得的匹配厂商版本，不无限遍历全部厂商历史。现有 .1/.2/.3 DBX 驱动包保留；最新 .3 重新构建当前工作树，避免遗漏已有修复。

增加 README.md、index.json、SHA256SUMS、来源/许可证和移植构建材料。索引区分 DBX 程序、厂商二进制、原始安装器、源码和移植材料，记录可用性、实际库路径、依赖、验证等级、来源版本和摘要。已保存不等于已被 DBX 支持；OceanBase 库与其本地源码补丁保留，但不新增 DBX 接入能力。不能取得的平台/厂商明确记录原因，不伪造安装包。

仅修改本次新增的分发工具、设计/计划和 .gitignore 的分发目录条目；不改已有驱动行为、系统驱动安装或用户未提交文件。不执行 Git add/commit/push。厂商原始包和许可证完整保留；索引不承诺未核实的再分发授权。所有文件摘要和归档清单完成验证，native Mac 运行采用本地闭端口/无凭据烟测；异构平台标注只编译/检查归档。
